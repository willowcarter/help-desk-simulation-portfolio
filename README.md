# Help Desk Simulation Portfolio

Selected IT support case studies completed using [ServiceDesk Simulator](https://servicedesk-simulator.com/), a hands-on IT help desk training platform.

These simulated cases demonstrate troubleshooting, remote support, ticket documentation, user communication, security awareness, and incident resolution. They are presented as training examples rather than professional work experience.

## Featured Cases

### [Active Directory: Password Reset & Account Recovery — INC0012855](tickets/active-directory-password-reset-INC0012855.md)

Troubleshot an expired domain password that prevented a user from logging into their workstation. Verified the user's identity, reviewed account status, performed an administrative password reset, and confirmed restored access.

**Skills:** Active Directory · Account Administration · Authentication Troubleshooting · Password Policy · Identity Verification

---

### [Hardware Replacement: Dead PC — INC0012871](tickets/hardware-replacement-dead-pc-INC0012871.md)

Troubleshot a workstation that was no longer functioning and documented the process for determining the appropriate hardware replacement and resolution path.

**Skills:** Hardware Troubleshooting · Workstation Support · Diagnostic Reasoning · Incident Documentation

---

### [Shared Drive Access Troubleshooting — INC0012847](tickets/shared-drive-troubleshooting-INC0012847.md)

Troubleshot a remote user's disconnected Marketing shared drive by establishing remote support, identifying a disconnected VPN connection, restoring VPN connectivity, and verifying access to the mapped network drive.

**Skills:** Remote Support · VPN Troubleshooting · Network Resources · Windows File Explorer · Business Impact Assessment · Resolution Verification

---

### [Legal Name Change: Account & Email Update — INC0012861](tickets/user-account-legal-name-change-INC0012861.md)

Processed a user's legal name change after verifying HR approval. Updated directory information and email attributes while preserving the existing username and previous email address as an alias to minimize disruption.

**Skills:** User Account Administration · Directory Management · Email Administration · Access Management · Change Management · Security Awareness

---

### [VPN Troubleshooting — NET17881134061420](tickets/vpn-troubleshooting-NET17881134061420.md)

Troubleshot a remote user's inability to reconnect to the corporate VPN. Used remote support and command-line network diagnostics, flushed the DNS resolver cache, restored VPN connectivity, and verified the active tunnel.

**Skills:** Remote Support · VPN Troubleshooting · DNS Troubleshooting · Network Diagnostics · Command-Line Troubleshooting · Security Awareness

---

### [Windows System Clock & Time Zone Correction — INC0012865](tickets/windows-system-clock-correction-INC0012865.md)

Resolved an incorrect Windows time zone and system clock through a remote support session. Corrected the workstation to Central Time, synchronized the clock, and confirmed the fix with the user.

**Skills:** Remote Support · Windows Configuration · Time Zone Configuration · System Time Synchronization · User Communication · Resolution Verification
