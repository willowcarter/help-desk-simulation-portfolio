- **Priority**: Low
- **User**: Amanda Foster / Amanda Reyes (`afoster@servicedesk-simulator.com`)
- **Department**: Finance
- **Request Type**: Account Update – Legal Name Change

#### Issue Description
User requested an update to her display name and primary email address following a legal name change post-marriage. HR approval was verified prior to making updates.

#### Technical Resolution Steps
1. **User Lookup**: Navigated to **Tools → Directory**, searched for the user profile (`afoster`), and accessed the **Profile** tab.
2. **Account Update**: Selected **Change Name & Email**:
   - Updated **Display Name** to `Amanda Reyes`.
   - Updated **Primary Email** to `areyes@servicedesk-simulator.com`.
3. **Email Alias Configuration**: Added the previous email (`afoster@servicedesk-simulator.com`) under **Aliases** to ensure uninterrupted delivery of ongoing email threads.
4. **Username Retention**: Retained the core username (`afoster`) to prevent disruptions to active domain logins, group memberships, and system permissions.
5. **Save & Confirm**: Saved changes and updated ticket status to Resolved.

#### Key Takeaways & Best Practices
- **HR Approval**: Always ensure HR has approved a legal name change before updating directory attributes.
- **Maintain In-Flight Communications**: Always preserve the original email address as an alias so the user does not miss incoming messages or replies to previous threads.
- **Minimize System Impact**: Retain existing usernames where possible to prevent broken application permissions, local profile corruption, or group policy issues.
