### 🛠️ INC0012871: Customer Support PC Dead / Power Failure

- **Priority**: Critical
- **User**: Quinn Adams (`qadams@servicedesk-simulator.com`)
- **Department**: Customer Support (Floor 1)
- **Business Impact**: Agent offline with active call queue blocked.

#### Issue Description
End-user reported that their desktop PC completely failed to power on (no lights, fan activity, or diagnostic beeps). User verified that the wall outlet was functional using another device.

#### Root Cause & Diagnosis
- **Root Cause**: Hardware failure (Power Supply Unit or motherboard failure).
- **Deployment Requirement**: Customer Support requires legacy softphone integration and on-premise device policies, necessitating a **Server Imaging** deployment rather than Cloud Provisioning.

#### Resolution Steps
1. **Hardware Verification**: Confirmed via Team Chat that the device remained unpowered on a known-good outlet and with an alternative power cable, confirming hardware failure.
2. **Device Specification**: Identified machine type as a Desktop needing server-based imaging.
3. **Provisioning**: Utilized `Computer Deployment` to build a replacement desktop configured via **Server Imaging**.
4. **Logistics & Dispatch**:
   - Acquired shipping address from user via Team Chat.
   - Dispatched replacement desktop from `Ship Manager` with **Rush Priority (Instant)**.
   - Enclosed a prepaid return label for dead unit recovery.
5. **Closure**: Confirmed delivery and recovery tracking; ticket resolved.

#### Key Lessons Learned
- Completely unpowered units (no fans/beeps/lights) indicate hardware failure—replace rather than attempt software troubleshooting.
- Hardware provisioning paths depend on role requirements (e.g., call-center agents require on-premise imaged builds over Cloud Identity).
- Always issue return labels during hardware replacements to maintain inventory control.
